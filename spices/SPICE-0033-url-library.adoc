= URL support in the standard library

* Proposal: link:./SPICE-0033-url-library.adoc[SPICE-0033]
* Author: link:https://github.com/stackoverflow[Islon Scherer]
* Status: TBD
* Implemented in: TBD
* Category: Standard Library

== Introduction

Add native URL support to Pkl's standard library.

== Motivation

Even though URLs are commonly used for configuration, Pkl has no out-of-the-box support for URLs.
There's a https://github.com/apple/pkl-pantry/tree/main/packages/pkl.experimental.uri[URI package in the pantry], but
it's not very performant due to being fully implemented in Pkl.
Also, the `Uri` typealias in our standard library is just a `String`, having no validation.

== Proposed Solution

This SPICE proposes a Pkl-native URL implementation in the standard library, exposing a native, performant parser,
that supports https://www.rfc-editor.org/rfc/rfc3986[RFC 3986] and https://www.rfc-editor.org/rfc/rfc6874[RFC 6874]
(IPv6 zone identifiers for link-local addresses).
Users will be able to create and alter URLs, with the guarantee they are well-formed. It will also be possible to
validate that a string is a URLs.

== Detailed design

=== Base design

A new stdlib module: `pkl:net`. +
We are using `net` and not `url`, because more functionality can be added later to `net` (like native IP support).

=== Parser

An RFC 3986 and RFC 6874 compliant parser implemented in Java, and exposed via the `Url(String)` constructor in the `net`
module. This constructor will throw on invalid URLs, like the `Regex(String)` constructor.
The parser will accept relative URLs (URL references in RFC 3986 parlance), and will be able to resolve a relative URL
in relation to an absolute one.
The parser is lenient: whatever cannot appear literally in a component is percent-encoded as its UTF-8 bytes, and
whatever is already percent-encoded is kept as written.
A `%` that does not begin a percent-encoded octet is still rejected.

[source,pkl]
----
/// Parse a string into a URL, following [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986).
/// Accepts a URL reference (one without a scheme).
///
/// This is lenient: whatever a component cannot hold literally is percent-encoded, and whatever is
/// already percent-encoded is kept as is.
///
/// Throws if [input] is not a valid URL.
///
/// To test if [input] is a valid URL, use [String.isValidUrl].
///
/// Facts:
/// ```
/// net.Url("https://example.com/foo?a=1").host == "example.com"
/// net.Url("https://example.com/foo?a=1").query == "a=1"
/// net.Url("https://example.com/a b").rawPath == "/a%20b"
/// net.Url("/foo").scheme == null
/// ```
external const function Url(input: String): Url
----

=== Url class

The `Url` constructor will return a `Url` object. This object will contain all the parts parsed, or constructed, like
`rawPath`, `scheme`, etc.
All the (non-external) properties will have constraints to make sure no invalid URLs can be created.
All base properties of Url are non-fixed to allow amendment.

Every component is held percent-encoded in its `raw` property, whether the parsed input was encoded or not.
A component that is set by hand, or amended, has to be percent-encoded already; a `rawPath` of `"/a b"` is rejected.
The percent-decoded form of each component is available as a `fixed` counterpart without the `raw` prefix:
`userInfo`, `host`, `path`, `query` and `fragment`.
This follows the naming convention of most URL libraries, such as `java.net.URI`, where `raw` stands for the form
that is still encoded.
To change a path without encoding it first, `resolve()` can be used, as it is as lenient as `Url()`.

[source,pkl]
----
/// A URL, as defined by [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986).
/// [RFC 6874](https://www.rfc-editor.org/rfc/rfc6874) IPv6 zone literals are also supported.
///
/// Every component is held percent-encoded, in its `raw` property, such as [rawPath]:
/// [Url()] encodes whatever a component cannot hold literally, and a component that is set by hand,
/// or amended, has to be encoded already.
/// The percent-decoded form of each component is available without the `raw` prefix, such as
/// [path].
///
/// Facts:
/// ```
/// net.Url("https://example.com/a b").rawPath == "/a%20b"
/// net.Url("https://example.com/a b").path == "/a b"
/// net.Url("https://example.com/a%20b").rawPath == "/a%20b"
/// ```
class Url {
  /// The scheme, without the trailing `:`, or [null] if this is a relative reference.
  ///
  /// [Url()] lowercases this, as schemes are case-insensitive.
  scheme: String(isValidScheme(this))? // <1>

  /// The percent-encoded userinfo, without the trailing `@`, or [null] if this URL has none.
  ///
  /// Only a URL with a [rawHost] can have userinfo.
  rawUserInfo: String(rawHost != null, isValidUserInfo(this))? // <1>

  /// The percent-encoded host, or [null] if this URL has no authority.
  ///
  /// A [null] host is not the same as an empty one: `file:/tmp` has no host, `file:///tmp` has an
  /// empty one.
  ///
  /// An IPv6 address must be enclosed in brackets, as in `[::1]`.
  /// It may carry a zone identifier, as described in RFC 6874.
  /// Anything else is a registered name, which cannot contain `[`, `]` or `:` literally.
  rawHost: String(isValidHost(this))? // <1>

  /// The port, or [null] if this URL states none.
  ///
  /// Only a URL with a [rawHost] can have a port.
  port: UInt16(rawHost != null)? // <1>

  /// The percent-encoded path, or the empty string if this URL has none.
  ///
  /// A URL with a [rawHost] has either an empty path or one starting with `/`.
  /// A URL without one may also have a *rootless* path, as `mailto:user@example.com` does.
  ///
  /// To change the path without encoding it first, use [resolve()], which is as lenient as [Url()].
  /// Unlike amending, this drops [rawQuery] and [rawFragment].
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/a?q=1#f").resolve("/b c").toString() == "https://example.com/b%20c"
  /// ```
  rawPath: String(isValidPath(this, rawHost != null)) = "" // <1>

  /// The percent-encoded query, without the leading `?`, or [null] if this URL has none.
  ///
  /// The empty string is a URL ending in a bare `?`.
  rawQuery: String(isValidQuery(this))? // <1>

  /// The percent-encoded fragment, without the leading `#`, or [null] if this URL has none.
  ///
  /// The empty string is a URL ending in a bare `#`.
  rawFragment: String(isValidFragment(this))? // <1>

  /// The percent-decoded [rawUserInfo].
  hidden fixed userInfo: String? = // <2>
    if (rawUserInfo != null) decodeUrlComponent(rawUserInfo) else null

  /// The percent-decoded [rawHost].
  hidden fixed host: String? = if (rawHost != null) decodeUrlComponent(rawHost) else null // <2>

  /// The percent-decoded [rawPath].
  ///
  /// An encoded `/` is decoded like any other octet, so it cannot be told apart from a `/` that
  /// separates segments; [pathSegments] keeps the two apart.
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/a%2Fb/c").path == "/a/b/c"
  /// net.Url("https://example.com/a%2Fb/c").pathSegments == List("a/b", "c")
  /// ```
  hidden fixed path: String = decodeUrlComponent(rawPath) // <2>

  /// The percent-decoded [rawQuery].
  ///
  /// Unlike [queryParameters], this does not read [rawQuery] as
  /// `application/x-www-form-urlencoded`, so a `+` is kept as is.
  hidden fixed query: String? = if (rawQuery != null) decodeUrlComponent(rawQuery) else null // <2>

  /// The percent-decoded [rawFragment].
  hidden fixed fragment: String? = // <2>
    if (rawFragment != null) decodeUrlComponent(rawFragment) else null

  /// Tells if this URL is absolute, that is, has a non-null scheme.
  hidden fixed isAbsolute: Boolean = scheme != null // <3>

  /// Tells if this URL's path is absolute, that is, starts with `/`.
  hidden fixed hasAbsolutePath: Boolean = rawPath.startsWith("/")

  /// The authority, without the leading `//`, or [null] if this URL has none.
  ///
  /// A URL has an authority exactly when it has a [rawHost].
  /// This is [rawUserInfo], [rawHost] and [port] joined back together.
  external fixed authority: String?

  /// What [rawHost] is, or [null] if this URL has no authority.
  ///
  /// - `"ipv6"`: an IPv6 address, such as `[::1]`
  /// - `"ipvFuture"`: an IP address of a version that RFC 3986 leaves for the future
  /// - `"ipv4"`: an IPv4 address in dotted-decimal form, such as `192.0.2.1`
  /// - `"name"`: any other host, a *registered name*
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/").hostKind == "name"
  /// net.Url("https://192.0.2.1/").hostKind == "ipv4"
  /// net.Url("https://[::1]/").hostKind == "ipv6"
  /// net.Url("/foo").hostKind == null
  /// ```
  external fixed hostKind: ("name" | "ipv4" | "ipv6" | "ipvFuture")?

  /// The percent-decoded zone identifier of an IPv6 [rawHost], as described in RFC 6874, or [null]
  /// if it states none.
  ///
  /// Facts:
  /// ```
  /// net.Url("http://[fe80::1%25eth0]/").zoneId == "eth0"
  /// net.Url("http://[fe80::1]/").zoneId == null
  /// ```
  external fixed zoneId: String?

  /// The percent-decoded segments of [rawPath].
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/a/b%20c").pathSegments == List("a", "b c")
  /// ```
  external fixed pathSegments: List<String>

  /// The percent-decoded parameters of [rawQuery], or an empty mapping if this URL has no query.
  ///
  /// [rawQuery] is read as `application/x-www-form-urlencoded`.
  /// A name that repeats holds the values of all its occurrences, in the order they are written.
  /// A parameter that states no `=` holds no value at all, and is left out; this is not the same as
  /// a bare `=`, which gives it the empty string.
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/?q=a+b&q=c").queryParameters["q"] == new Listing { "a b"; "c" }
  /// net.Url("https://example.com/").queryParameters.isEmpty
  /// ```
  external fixed queryParameters: Mapping<String, Listing<String>>

  /// Resolves [ref] against this URL.
  ///
  /// [ref] is either a relative reference, which is resolved against this URL, or an absolute URL,
  /// which replaces it entirely.
  /// Dot segments (`./` and `../`) are removed from the result's path, normalizing it.
  ///
  /// Throws if [ref] is a string that cannot be parsed, or if this URL is itself a relative
  /// reference.
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/a/b").resolve("../c").toString() == "https://example.com/c"
  /// net.Url("https://example.com/a/b").resolve("#top").toString() == "https://example.com/a/b#top"
  /// ```
  external function resolve(ref: String | Url): Url

  /// Returns this URL in the *syntax-based normalization* of
  /// [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986#section-6.2.2).
  ///
  /// [scheme] and [rawHost] are lowercased, as they are case-insensitive.
  /// Percent-encoding is normalized: an octet standing for an unreserved character is decoded, and
  /// any other octet is kept, with its hex digits uppercased.
  ///
  /// Dot segments (`./` and `../`) are only removed from an absolute [rawPath].
  /// A URL with a [rawHost] and no path is given the path `/`, which names the same resource.
  ///
  /// Normalization that would require knowing the scheme is not performed.
  ///
  /// Two URLs identify the same resource exactly when their normalizations are equal; this is what
  /// [equals()] compares.
  ///
  /// Facts:
  /// ```
  /// net.Url("HTTPS://Example.com/%7Euser").normalize() == net.Url("https://example.com/~user")
  /// net.Url("https://example.com/a/b/../c").normalize().rawPath == "/a/c"
  /// net.Url("https://example.com").normalize().rawPath == "/"
  /// ```
  external function normalize(): Url

  /// Whether [other] identifies the same resource as this URL.
  ///
  /// Unlike `==`, this compares Urls as the *syntax-based normalization* of RFC 3986:
  /// [scheme] and [rawHost] are case-insensitive and percent-encoding is normalized.
  /// An octet standing for a reserved character is kept as written.
  ///
  /// Dot segments (`./` and `../`) are only removed from an absolute [rawPath].
  ///
  /// Normalization that would require knowing the scheme is not performed.
  ///
  /// Facts:
  /// ```
  /// net.Url("HTTPS://Example.com/%7Euser").equals(net.Url("https://example.com/~user"))
  /// !(net.Url("https://example.com/a%2Fb").equals(net.Url("https://example.com/a/b")))
  /// !(net.Url("https://example.com:443/").equals(net.Url("https://example.com/")))
  /// ```
  external function equals(other: Url): Boolean

  /// The serialization of this URL.
  ///
  /// Facts:
  /// ```
  /// net.Url("https://example.com/a b").toString() == "https://example.com/a%20b"
  /// net.Url("https://example.com/é").toString() == "https://example.com/%C3%A9"
  /// net.Url("HTTPS://example.com").toString() == "https://example.com"
  /// ```
  external function toString(): String

  /// Whether [value] is a percent-encoded `userinfo`.
  external function isValidUserInfo(value: String): Boolean

  /// Whether [value] is a `scheme`.
  external function isValidScheme(value: String): Boolean

  /// Whether [value] is a percent-encoded `host`.
  external function isValidHost(value: String): Boolean

  /// Whether [value] is a percent-encoded path that can sit next to an authority, or, when
  /// [hasAuthority] is [false], next to no authority at all.
  external function isValidPath(value: String, hasAuthority: Boolean): Boolean

  /// Whether [value] is a percent-encoded `query`.
  external function isValidQuery(value: String): Boolean

  /// Whether [value] is a percent-encoded `fragment`.
  external function isValidFragment(value: String): Boolean
}
----
<1> All components are stored percent-encoded and are validated
<2> The percent-decoded components are `fixed`, so they cannot be amended
<3> URLs can be relative

Examples:

[source,pkl]
----
import "pkl:net"

local url = net.Url("https://user:pw@example.com:8080/a/b c?q=ä b&null&empty=#f")

myUrl = url.toString() // <1>

host = url.host // <2>

rawPath = url.rawPath // <3>

path = url.path // <4>

query = url.queryParameters // <5>

resolved = url.resolve("../d/e").toString() // <6>

amended = (url) {
  rawHost = "another.com"
  port = null
  rawPath = "/x%20y"
}.toString() // <7>
----
<1> "https://user:pw@example.com:8080/a/b%20c?q=%C3%A4%20b&null&empty=#f"
<2> example.com
<3> "/a/b%20c"
<4> "/a/b c"
<5> `new Mapping { ["q"] { "ä b" }; ["empty"] { "" } }` (`null` states no `=`, so it is left out)
<6> "https://user:pw@example.com:8080/d/e"
<7> "https://user:pw@another.com/x%20y?q=%C3%A4%20b&null&empty=#f" (an amended `rawPath = "/x y"` would be rejected)

=== URL validation

A new external property will be added to the String class: `external isValidUrl: Boolean`.
Similar to how `isRegex` works, this property will tell if a string is a valid URL.
The `Uri` typealias in base will be redefined as `typealias Uri = String(isValidUrl)`.
This is a breaking change, but if this fails, you have an invalid URL and should fix it.

This validation is stricter than the one from the regular `Url()` constructor:

- It only accepts absolute URLs
- All components should be properly encoded

=== Helper functions

Some helper functions are needed to help build or extract information from URLs.

[source,pkl]
----
/// Percent-encodes [value] so that it can be interpolated into any URL component.
///
/// Every character other than an ASCII alphanumeric or one of `-._~`, the *unreserved* characters
/// of RFC 3986, is percent-encoded as its UTF-8 bytes.
///
/// Facts:
/// ```
/// net.encodeUrlComponent("a b&c") == "a%20b%26c"
/// net.encodeUrlComponent("50%") == "50%25"
/// ```
external const function encodeUrlComponent(value: String): String // <1>

/// Percent-decodes [value], interpreting the decoded bytes as UTF-8.
///
/// The inverse of [encodeUrlComponent()].
///
/// Throws if any `%` in [value] does not begin a percent-encoded octet.
/// To write a literal `%`, encode it as `%25`.
///
/// Facts:
/// ```
/// net.decodeUrlComponent("a%20b%26c") == "a b&c"
/// net.decodeUrlComponent("50%25") == "50%"
/// ```
external const function decodeUrlComponent(value: String): String // <1>

/// Builds a query from [parameters], for use as a [Url.rawQuery].
///
/// The result is `application/x-www-form-urlencoded`.
/// A name is written once per value it holds; one that holds no values is left out entirely.
///
/// [Url.queryParameters] reads back exactly the parameters given here, less any name that holds no
/// values.
///
/// Facts:
/// ```
/// net.buildQuery(new Mapping { ["q"] = new Listing { "a b" } }) == "q=a+b"
/// net.buildQuery(new Mapping { ["a"] = new Listing { "1"; "2" } }) == "a=1&a=2"
/// net.buildQuery(new Mapping { ["a"] = new Listing { "1" }; ["b"] = new Listing {} }) == "a=1"
/// ```
external const function buildQuery(parameters: Mapping<String, Listing<String>>): String // <2>

/// Reads [query] back into its parameters.
///
/// [query] is read as `application/x-www-form-urlencoded`.
/// A name that repeats holds the values of all its occurrences, in the order they are written.
/// A parameter that states no `=` holds no value at all, and is left out.
///
/// Throws if any `%` in [query] does not begin a percent-encoded octet.
///
/// Facts:
/// ```
/// net.parseQuery("a=1&a=2") == new Mapping { ["a"] = new Listing { "1"; "2" } }
/// net.parseQuery("q=a+b&bare") == new Mapping { ["q"] = new Listing { "a b" } }
/// ```
external const function parseQuery(query: String): Mapping<String, Listing<String>>
----
<1> Percent encode/decode components
<2> Encode a mapping of strings into a query

The decoding functions are strict: a `%` that does not begin a percent-encoded octet is an error, not a literal `%`.
This matches the `Url` parser, which rejects such a `%` in every component.
It also avoids a silent ambiguity: a lenient decoder turns both `100%` and `100%25` into `100%`, which hides
a value that was not encoded, or was encoded incorrectly.

RFC 3986 does not define `application/x-www-form-urlencoded`, so `buildQuery()` and `parseQuery()` follow the
https://url.spec.whatwg.org/#application/x-www-form-urlencoded[WHATWG URL Standard] for it.
Only the ASCII alphanumerics and `*-._` are left unencoded, and a space is written as `+`.
This differs from `encodeUrlComponent()` in two characters: `~` is encoded, and `*` is not.

=== Language bindings

Our language bindings will turn a `net.Url` into the corresponding URL type in the target language.

|===
|Language |Type

|Swift
|https://developer.apple.com/documentation/foundation/url[`URL`] (Foundation)

|Java/Kotlin
|https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/net/URI.html[`java.net.URI`] footnote:[Java also has a URL type, but its https://bugs.java.com/bugdatabase/view_bug.do?bug_id=4434494[usage is strongly discouraged].]

|Go
|https://pkg.go.dev/net/url[`net/url`]
|===

Third party language binding implementors are encouraged to map `net.Url` into their language's built-in URL type,
if there is one.

==== Message format

When serialized, `net.Url` will be encoded as a `Typed` object (see https://pkl-lang.org/main/current/bindings-specification/binary-encoding.html#non-primitives).

The client in the host language will turn the URL into the target language via their respective codec/mapper/unmarshaller.

When decoding, the language has to construct the URL component-wise (using a constructor and using `scheme`, `rawHost`,
etc. individually).

== Compatibility

Compatibility with `pkl.experimental.uri` was not a goal, but the two libraries are relatively similar (both based
on RFC 3986).

The `read(String)` and `read?(String)` primitives were not touched.

The change to the `Uri` typealias is backward incompatible, but considered a bugfix.

== Future directions

More functions/properties can be added to the Url class, like `relativize`.
A lenient way to amend a single component, encoding it the way `Url()` does, could also be added.

IDNA, punnycode support could be added, if needed.

If we add an IO/path API to Pkl we can convert between file URLs and paths. Same for native IP support: we can add
properties to get an IP out of the host.

== Alternatives considered

=== Do nothing and keep using `pkl.experimental.uri`

Performance suffers from having the parser in Pkl. It also can't solve the validation problem
which should be added to the base String class.

=== Use WHATWG instead of RFC 3986

WHATWG is a more complex spec, with validations that require full URL context, so it's harder to add constraints to parts of an URL.
It also requires IDNA support, which would add a lot of complexity to the implementation.

=== Hold components percent-decoded

Components could be held percent-decoded, and only encoded when the URL is stringified.
This is simpler to amend, but it loses information: an encoded reserved character, such as the `%2F` in `/a%2Fb`,
cannot be told apart from its literal form once decoded.
A URL would then not round-trip through `Url()` and `toString()`.
Holding components encoded keeps them exact, and the properties without the `raw` prefix still give the decoded form.
